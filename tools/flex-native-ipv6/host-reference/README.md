# Archived native acceptance and recovery sources

These four original MIT files are preserved unchanged for review of the bounded
acceptance/recovery design. They contain no deployment transport or bootstrap.
They are not a turnkey installer, and importing them does not activate the job.
The native executor supplied `WORKDIR` to run the guarded module entry point.

Both jobs pin the tested library SHA256:
`75c4cf13d407c037b430dd5d8639c6d0bb12a8598fba0c74e11afef7c16cd355`.
An independently rebuilt binary need not have that identity. The fake tests
also read `shim/libnereus_ipv6.so` adjacent to their original working tree;
that generated artifact and original layout are intentionally absent here.
The unchanged tests are archival examples, not runnable source-only package tests.
An owner retaining the exact recorded artifact can reproduce them in disposable
scratch storage: copy these four Python files to one scratch directory, create
its `shim/` child, place that recorded `libnereus_ipv6.so` there, verify the SHA
above, then run `python3 -m unittest discover -p 'test_host_smartsdr_*.py'`
from that scratch directory. The tests inject fake system state and do not run
the native host jobs. Do not substitute a rebuilt binary and remove hash checks.

Execution requires an owner-authorized native host-root environment, Python 3,
systemd, host `/proc`, native IPv6, `smartsdr.service`, and the installed vendor
`inhibit-power-pic.service`. Their filesystem `root` parameter supports injected
fake tests; it does not sandbox real systemctl commands. The diagnostic SSH
container does not supply this native administrative scope.

Acceptance checks exact artifact ownership before writing a stable library and
current-boot `/run/systemd/system/smartsdr.service.d/90-nereus-ipv6.conf`.
An independent 300-second rollback timer is verified before service activation.
It starts the vendor power-controller guard before restarting SmartSDR, checks
process maps and selected/untouched sockets, and waits up to 180 seconds for
administrative acceptance. Failure attempts guarded recovery and independent
retry; recovery races prevent retaining the experiment.

The exact local ACK is `{"accept":true}` on `127.0.0.1:46861`; that protocol has
no authentication of its own. In the experiment the owner used authenticated
SSH in a controlled host environment. Do not expose this ACK listener through
a published port. The owner must separately evaluate the client result before
accepting retention. No client or RF command is generated by these jobs.

Revert verifies exact library/drop-in ownership, reloads systemd, starts the
vendor guard and restarts stock SmartSDR. It retries recovery and checks that
the library is no longer mapped before unlinking it. The original private
owner access path, credentials, waveform bridge/root-FD helper and generated
artifacts are deliberately excluded; no substitute deployment automation is
provided here.
